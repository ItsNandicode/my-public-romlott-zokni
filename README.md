## Tailwind Setup

Two Tailwind config files are included. Use `src/index-v4.css` if you're on Tailwind v4, or `tailwind.config.js` if you're on v3 — delete the one you don't need.

**Tailwind v4** (default): This project's `devDependencies` include `tailwindcss@^4` and `@tailwindcss/vite`. Just run `npm install` and you're set. The v4 theme file lives at `src/index-v4.css`.

**Tailwind v3**: Replace `tailwindcss@^4` with `tailwindcss@^3`, add `postcss` and `autoprefixer` to `devDependencies`, remove the `@tailwindcss/vite` plugin from `vite.config.ts`, and delete `src/index-v4.css`. The v3 config file is `tailwind.config.js`.
